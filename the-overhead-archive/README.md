## ✦ About The Project

**The Overhead Archive** is a personal photographic journal that looks upward.

The project captures ordinary moments in the sky and transforms them into a visual sequence — clouds, sunlight, rain, sunrise, moonlight, rooftops, and the spaces between them.

Instead of functioning as a conventional photography portfolio, the website is designed to feel like a **digital photo book**. 📖

The photographs are presented alongside the poetic imagery of Percy Bysshe Shelley's *The Cloud*, creating a connection between:

📸 Photography  
☁️ The sky  
📖 Poetry  
🌅 Light  
🌧️ Weather  
🌙 Night  
🕰️ Memory

The visual identity combines:

- 📚 Independent photography publication
- 📰 Editorial design
- 📖 Literary archive aesthetics
- 🎞️ Vintage photo-book influence
- ☁️ Atmospheric visual storytelling
- ✨ Minimal typography
- 🖤 Dark editorial elements
- 🤍 Warm paper-like backgrounds

The goal was simple:

> **Make the website feel like a photographic book that happens to exist on the web.**

## 📖 Literary Inspiration

The project is inspired by Percy Bysshe Shelley's **_The Cloud_**.

The poem's imagery of:

🌧️ Rain  
☀️ Sunlight  
⚡ Lightning  
🌅 Sunrise  
☁️ Clouds  
🌙 Moonlight  

provides the literary atmosphere surrounding the photographic sequence.
